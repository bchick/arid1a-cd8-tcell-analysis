This repository reproduces, from the raw sequencing reads, the computational analyses in:

> McDonald B\*, Chick BY\*, Ahmed NS, Burns M, Ma S, Casillas E, Chen D, Mann TH, O'Connor C, Hah N, Hargreaves DC, Kaech SM. **Canonical BAF complex activity shapes the enhancer landscape that licenses CD8⁺ T cell effector and memory fates.** *Immunity* 56(6):1303–1319 (2023). [doi:10.1016/j.immuni.2023.05.005](https://doi.org/10.1016/j.immuni.2023.05.005) · GEO [GSE228381](https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=GSE228381)
> \*equal contribution

All 128 ATAC-seq, RNA-seq, CUT&RUN and ChIP-seq libraries were reprocessed on GRCm39 (mm39, GENCODE vM35) with containerized nf-core pipelines. Each computational panel of the paper is then regenerated by its own script. The repository also includes analyses that go beyond the paper, and a comparison with an independent cBAF dataset (Guo *et al.* 2022, *Nature*).

## Quick start

Requirements: Linux x86-64, R 4.4, Python ≥ 3.10, about 16 GB RAM and about 2 GB of disk. You don't need the sequencing data.

```bash
git clone https://github.com/bchick/arid1a-cd8-tcell-analysis.git
cd arid1a-cd8-tcell-analysis

USE_BUNDLED_LIBUV=1 Rscript -e 'renv::restore()'   # R packages -> project library (renv.lock)
pip install -r requirements.txt                     # Python helpers

make fetch-data      # download + verify the processed-data bundle (~330 MB, Zenodo)
make figures         # every reproducible panel of the paper -> figures/paper/
make validate        # checksums + headline numbers
```

The project's `.Rprofile` bootstraps renv, so packages go into a library private to this project and your own R library is left alone. The lockfile pins Bioconductor 3.20 on R 4.4. Most packages build from source; `USE_BUNDLED_LIBUV=1` lets `fs` build without the system `libuv` headers.

`make extensions` and `make meta` build the analyses beyond the paper and the Guo *et al.* comparison. `make extensions` also needs `git` and [pixi](https://pixi.sh): the WT vs KO trajectory classes (`extended_analysis/scripts/atac_trajectories/01_timecourse_patterns.sh`) run [timecourse-patterns](https://github.com/bchick/timecourse-patterns) at a pinned commit, in its own locked environment under `external/`. `make all` runs everything. Each panel writes a figure to `figures/paper/` and the table behind it to `results/paper/`. For comparison, reference renders are in `results/reference/`.

## What is reproduced

`PANEL_MAP.md` lists every panel of the paper and supplement. For each one it gives the script that produces it, whether it reproduces, and how it differs from the publication. In summary:

- **Reproduced:** Figs. 1A–D, 1F, 2C–I, 3E–I, 4A–E, 5A, 5C–J, 6A and the computational supplementary panels (S1A–C, S2D, S4, S5A, S6A). The published Fig. 1 OCR clusters are included (`data/metadata/paper_ocr_clusters/`), so all cluster-based panels use the paper's own region sets.
- **Not reproducible from GSE228381:** Figs. 1E, 1G and 5B need external histone or TF ChIP data. For most signatures in Fig. 3I, the external data were not reprocessed.
- **Wet-lab panels** (flow cytometry, cell counts, titres) are listed but are not computational.

**Known differences from the paper.** They are documented in `PANEL_MAP.md` and `docs/methods.md` §10.

- **Pipelines.** The paper used mm10 with STAR and HOMER. This reanalysis uses mm39, nf-core, MACS2/SEACR and DESeq2 with apeglm.
- **DEG threshold.** The paper's legends say 2-fold, but its Methods say 1.5-fold. DEG counts are reported at both thresholds.
- **Inhibitor ATAC normalization.** The ACBI1/BRM014 libraries lose FRiP globally, so the number of inhibitor-sensitive OCRs depends on how libraries are normalized. Both normalizations are reported.

## Workflows

| Target | Scripts | Needs |
|---|---|---|
| `make core` | `scripts/core/01`–`05`: RNA-seq DE, ATAC-seq DA, temporal clustering, CUT&RUN, ChIP | bundle |
| `make figures` | `scripts/paper/*.R`: panel-by-panel reproduction | bundle |
| `make extensions` | `extended_analysis/scripts/*/` except `guo2022/` and `qc_audit/` | bundle; pixi for `atac_trajectories/` |
| `make meta` | `extended_analysis/scripts/guo2022/`: Guo *et al.* 2022, then `qc_audit/` | bundle; Docker for `04_diffbind216.R` |
| `make upstream` | `scripts/upstream/` (download, nf-core) and heavy precompute | raw data, see below |

**Extensions beyond the paper.** Code is in `extended_analysis/scripts/<analysis>/`, numbered in run order. Outputs go to `results/extended_analysis/<analysis>/` and `figures/extended_analysis/<analysis>/`; the summary figures are listed in `results/reference/extended_analysis/figure_manifest.md`.

| Analysis | Folder | What it does |
|---|---|---|
| ARID1A dose response | `het_dose_response/` | Classifies OCRs by their response to *Arid1a* dosage (WT vs Het vs KO) as buffered, haploinsufficient, linear and so on, then compares features and motifs between classes. Report: `docs/reports/het_dose_response.md`. |
| chromVAR and TOBIAS | `chromvar/`, `footprinting/` | Motif accessibility and TF footprinting across the allelic series. Report: `docs/reports/tobias_footprinting.md`. |
| Temporal clustering | `temporal_clustering/` | WT and KO accessibility trajectories (degPatterns, k-means, Mfuzz). |
| Trajectory classes and ARID1A loss | `atac_trajectories/` | Dynamic peaks called separately in the WT and KO timecourses with [timecourse-patterns](https://github.com/bchick/timecourse-patterns). Sites dynamic in WT but not in KO are clustered by their WT trajectory, and KO is projected onto the WT classes (`01`–`03`). Motif enrichment of the lost sites (`04`–`05`); whether the TFs behind those motifs are down-regulated in time-matched RNA-seq (`06`); held-out elastic-net motif models adjusted for GC, CpG and promoter status (`07`). |
| Motif grammar | `motif_grammar/` | Tests whether motif spacing or orientation predicts dose sensitivity beyond motif composition. It does not (a documented null). Report: `docs/reports/motif_grammar.md`. |
| Multi-omic integration | `integration/` | Links D8 KO vs WT accessibility, expression and ARID1A binding at the gene level. |
| Cross-study comparison | `guo2022/` | Guo *et al.* 2022 Arid1a KO and inhibitor RNA/ATAC, reprocessed identically. Their GSE183618 "WT" samples come from two separate experiments and must not be pooled; see `docs/methods.md` §8. |
| QC audit | `qc_audit/` | Retrospective QC checks across every differential contrast, including Guo's; runs at the end of `make meta`. |
| Summary figures | `figures/` | Figures that combine results across the analyses above. |

## Recomputing from upstream data

The raw-data path regenerates everything in the bundle. It needs Docker (or Singularity), Nextflow ≥ 24, about 50 TB of scratch space and about 400 GB RAM. It was tested on 64 cores and 503 GB.

1. Put the mm39 references in `data/reference/` (see `DATA_ACCESS.md`).
2. `make upstream-download`: downloads FASTQs from ENA with MD5 checks (sample sheets in `data/metadata/`).
3. `make upstream-nfcore`: runs nf-core/atacseq 2.1.2, rnaseq 3.22.2, cutandrun 3.2.2 and chipseq 2.1.0 (`nextflow/nextflow.config`; set `ARID1A_PROJECT_DIR` or launch from the repo root).
4. `make upstream-precompute`: runs TOBIAS, chromVAR, deepTools matrices and HOMER.
5. To rebuild the bundle: `python3 tools/export_bundle.py`.

The tool versions used are listed in `data/metadata/software_versions.tsv` and `renv.lock`, and command-line tools can be installed with `environment.yml`.

## Repository layout

```
Makefile              entry points (make figures | extensions | meta | upstream)
scripts/
  core/               01-05: DE/DA, temporal clustering, CUT&RUN, ChIP that the panels build on
  paper/              one script per published panel (+ utils_paper.R)
  upstream/           FASTQ download, sample-sheet builders, nf-core launchers
  utils.R             shared paths, palettes and helpers
extended_analysis/
  scripts/<analysis>/ analyses beyond the paper (see the table above)
nextflow/             shared Nextflow config + per-pipeline samplesheets
data/metadata/        sample sheets, ENA/SRA run tables, published OCR clusters,
                      software versions
docs/
  methods.md          full computational methods
  reports/            write-ups of the extended analyses
results/reference/    reference renders of every figure
tools/                bundle fetch/export, release validation
PANEL_MAP.md          paper panel -> script -> status
DATA_ACCESS.md        accessions, bundle DOI, reference genome sources
```
